## Explicit differences, not Sprint 5 blockers

| Report detail | Current implementation | Classification |
| --- | --- | --- |
| User `profile_image` and Seller uploaded photo | Seller uses a generated initial avatar; upload/edit was never assigned in Sprint 4 or 5 | Known medium product gap |
| Category/Game `image` fields | Taxonomy is text/status based; listing media is fully implemented | Known medium visual enhancement |
| “SystemSettings key/value” generic table | Typed singleton columns are used for rate, fee and auto-confirm hours | Intentional safer implementation difference |
| Admin advanced analytics | Operational counts and ledger/audit recency only | Correctly outside MVP advanced analytics |
| Socket.IO/realtime presence | 5-second polling | Explicitly outside MVP/optional in the report |
| Real payment/bank integration | Simulation only | Explicitly outside MVP |

No Sprint 5 acceptance item depends on the two image-field enhancements. They are documented instead of silently claiming exact parity.
